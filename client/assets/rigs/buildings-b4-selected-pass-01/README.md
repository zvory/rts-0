# B4 selected building pass

Selected B variants promoted after an in-game comparison against the accepted Vehicle Works.

- `steelworks-magenta.png`: Gun Works B, a single open artillery assembly hall with a visible
  cannon and steel press.
- `engineering_complex-magenta.png`: Laboratory B, dominated by a geodesic glass roof dome.

Both buildings use a 3×3, 384 px runtime frame. Their atlases contain fixed-color, team-tint,
and blurred offset silhouette-shadow frames with fully transparent outer pixels.
