# Resource Depot worksite preview — retained prompt brief

## Base worksite

Use case: stylized-concept

Asset type: top-down RTS building atlas source

Primary request: an open, fenced resource-processing worksite rather than a closed building;
include muddy packed-earth ground, an oil storage silo, a small hot foundry/furnace, crane,
stacked steel, oil barrels, tools, and a service truck.

Style/medium: hand-painted, high-detail top-down game asset matching the existing RTS buildings;
orthographic/Pokémon-like readable forms; 1940s-industrial character; no people, text, logos, or
cast scene outside the worksite.

Backdrop: flat magenta chroma-key background. Keep the full asset inside a square canvas.

## Team-paint edit

Edit only selected silo, fence, crane, and equipment-painted surfaces to neutral white so runtime
team tint can recolor them. Preserve the worksite layout and all non-team-painted materials. Keep a
flat magenta background.

## Wrench emblem

Use case: logo-brand

Asset type: team-tinted building emblem

Primary request: one simplified diagonal wrench silhouette, with a white fill and a heavy black
outline, on a flat magenta chroma-key background. No backing plate, text, shadow, extra tools, or
decorative details. Leave generous edge padding.

The checked-in runtime emblem is a deterministic reduction/outline pass of the selected wrench;
its white fill is multiply team-tinted while the black outline remains fixed.
